# Prior art

ETM's core idea is old. This file names who got there first, what each established, and what each offers the open problems this program works on. It also states what ETM would have to add to be more than a restatement. Every novelty claim below is **open** until outside reviewers have checked it against this list.

Citation status: **checked** = verified against a publisher, journal, or index listing on 2026-10-27; **standard** = a widely cited work, cited from general knowledge, not yet re-checked here. Primary texts are to be read before anything is quoted from them.

## What ETM would have to add

Each of these is a claim of novelty, and each is **open** until checked against the works above by someone other than the authors.

1. **The two-way, every-scale claim as a research program.** Prior work mostly runs one direction at a time (economics applied to AI, or the economy described as a mind). ETM's program is to make the correspondence explicit, keep a fixed dictionary, and score transfers in both directions.
2. **Adversarial, permissionless substrates as the test.** Blockchains expose an economy of contribution to real attackers with real money. The measured result from Noesis, that no structural signal inside a contribution graph cleanly separates a competent wash from real work, is a hard data point for every level of the correspondence.
3. **Grounding as a named, necessary condition.** Several prior systems use it without naming it as a law (Hayek's outside payment, host sanctions, biological markets). ETM's candidate claim is that relational prices track worth only when they bottom out in minds outside the contributor's control, at every scale.
4. **Persistent memory of AI agents as a substrate.** Possibly anticipated by the 2026 Economy of Minds paper; not claimed until it is read.
